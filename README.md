# Pulse — Next-gen Todo

A modern Todo workspace built with Next.js and React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Features
- Next.js App Router
- Dark/light mode
- LocalStorage persistence
- Priority-based tasks
- All/Open/Done filters
- Completion progress ring
- Responsive UI
- ESLint + production build scripts
